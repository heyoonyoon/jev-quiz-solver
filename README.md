# QuizN Auto Solver

실시간 퀴즈를 자동으로 푸는 크롬 확장 프로그램입니다. 문제가 뜨면 0.2초 안팎에 정답 버튼을 누릅니다.

![시연 영상](docs/demo.gif)

문제마다 걸린 시간은 0.2초, 0.2초, 0.2초, 0.2초, 0.5초입니다.

## 문제

문제를 풀려면 먼저 문제를 알아야 하는데, 참가자인 제 화면에는 보기 버튼 네 개만 나오고 문제 글은 교수님 화면에만 떠 있었습니다.

## 가장 먼저 든 생각

제 화면이 보기 버튼을 그리려면 어딘가에서 문제 정보를 받아 올 것 같아서 퀴즈를 하는 동안 개발자 도구의 Network 탭을 HAR 파일로 저장해 분석했습니다. 교수님이 다음 문제로 넘기면 서버가 STOMP over SockJS 웹소켓으로 신호를 보내고, 참가자 페이지는 보기 화면을 받기 위해 `POST /quz/realtime/v2/clientQuizDetail.do`를 호출합니다. 이 요청의 form 본문에 `question`과 `selOptn1Text`부터 `selOptn4Text`까지 문제와 보기가 평문으로 들어 있었고, 화면에서 문제를 숨기는 것은 함께 넘어가는 `questionViewFlg=0` 값뿐이었습니다. 정답 값은 어디에도 없고 채점은 서버가 하므로, 정답은 직접 풀어야 했습니다.

## 구현

이 요청을 가로채는 크롬 확장 프로그램을 만들었습니다. 페이지 컨텍스트에 주입한 스크립트가 `XMLHttpRequest`를 감싸 `clientQuizDetail.do` 요청이 나가는 순간 본문에서 문제와 보기를 꺼내고, 백그라운드 서비스 워커가 제미나이에게 정답 번호만 답하게 합니다. 번호가 오면 해당 보기 버튼(`#optn1`부터 `#optn4`)을 클릭하는데, 이 퀴즈는 보기를 누르면 바로 제출되므로 클릭 한 번으로 끝납니다.

## 추가 문제

실제 퀴즈에서 전부 맞혔지만 답이 오기까지 1초 정도 걸렸습니다. 퀴즈앤은 빨리 답할수록 점수가 높아서 1등을 하려면 1초도 길었고, 제미나이 같은 언어 모델은 답을 글자로 한 자씩 만들어 내기 때문에 숫자 하나를 받는 데도 시간이 듭니다.

## JEV

마침 이런 판단만 전문으로 하는 결정 모델 Jev가 나와 있었습니다. Jev는 글을 만들지 않고 주어진 보기마다 확률을 한 번에 계산해서 고르기 때문에 훨씬 빠릅니다. 최소 결제 금액이 5달러라서 5달러를 충전했는데, 한 문제에 0.01원 정도라 사실상 평생 쓸 수 있는 양입니다.

![TypeSafe 결제 화면](docs/billing.png)

## 해결

Jev 공식 문서에는 한국어 같은 언어는 성능을 따로 확인하라고 적혀 있어서 Jev 하나만 믿기는 불안했습니다. 그래서 문제가 오면 Jev와 제미나이에게 동시에 묻고, Jev가 고른 보기의 확률이 0.7 이상이면 바로 누르고 그보다 낮으면 제미나이의 답을 기다리도록 했습니다. Jev가 확신하는 대부분의 문제는 0.2초 안팎에 끝나고, 애매한 문제도 예전처럼 1초 정도면 풀립니다.

| 방식 | 강의자료 문제 정답 | 걸린 시간 |
|---|---|---|
| 제미나이만 사용 | 15문제 중 15문제 | 약 1.1초 |
| Jev와 제미나이 동시 사용 | 17문제 중 17문제 | 약 0.2초 |

## 설치

1. `extension/config.example.js`를 `extension/config.js`로 복사하고 Google AI 키와 TypeSafe 키를 넣습니다.
2. 크롬 `chrome://extensions`에서 개발자 모드를 켜고 `extension` 폴더를 압축해제된 확장 프로그램으로 불러옵니다.
3. 퀴즈앤 참가 화면을 새로고침한 뒤 PIN으로 들어가면 문제가 뜰 때마다 알아서 답을 누릅니다.
