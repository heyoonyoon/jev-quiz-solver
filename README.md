# QuizN Auto Solver

수업 시작 전에 과자를 걸고 하는 퀴즈앤(quizn.show) 실시간 퀴즈를 자동으로 푸는 크롬 확장 프로그램이다. 문제가 뜨면 0.2초 안팎에 정답 버튼을 누른다.

![시연 영상](docs/demo.gif)

5문제를 모두 맞혀 1등을 했고, 문제마다 걸린 시간은 0.2초, 0.2초, 0.2초, 0.2초, 0.5초였다.

## 문제는 내 화면에 없었다

문제를 풀려면 먼저 문제를 알아야 하는데, 참가자인 내 화면에는 보기 버튼 네 개만 나오고 문제 글은 교수님 화면에만 떠 있었다. 그래도 내 화면이 보기 버튼을 그리려면 어딘가에서 문제 정보를 받아 올 것 같아서 개발자 도구로 네트워크를 열어 봤고, 예상대로 문제가 바뀔 때마다 브라우저가 보내는 요청 안에 문제와 보기 네 개가 글자 그대로 들어 있었다.

## 제미나이로 풀기

그래서 이 요청을 가로채는 확장 프로그램을 만들었다. 요청이 나가는 순간 문제와 보기를 꺼내 제미나이에게 정답 번호만 답하게 하고, 받은 번호의 보기 버튼을 대신 누른다. 실제 퀴즈에서 전부 맞혔지만 답이 오기까지 1초 정도 걸렸다.

## 1초도 길다

퀴즈앤은 빨리 답할수록 점수가 높아서 1등을 하려면 1초도 길었다. 제미나이 같은 언어 모델은 답을 글자로 한 자씩 만들어 내기 때문에 숫자 하나를 받는 데도 시간이 드는데, 마침 이런 판단만 전문으로 하는 결정 모델 Jev가 나와 있었다. Jev는 글을 만들지 않고 주어진 보기마다 확률을 한 번에 계산해서 고르기 때문에 훨씬 빠르다. 최소 결제 금액이 5달러라서 5달러를 충전했는데, 한 문제에 0.01원 정도라 사실상 평생 쓸 수 있는 양이다.

![TypeSafe 결제 화면](docs/billing.png)

## Jev와 제미나이를 같이 쓰기

Jev 공식 문서에는 한국어 같은 언어는 성능을 따로 확인하라고 적혀 있어서 Jev 하나만 믿기는 불안했다. 그래서 문제가 오면 Jev와 제미나이에게 동시에 묻고, Jev가 고른 보기의 확률이 0.7 이상이면 바로 누르고 그보다 낮으면 제미나이의 답을 기다리도록 했다. Jev가 확신하는 대부분의 문제는 0.2초 안팎에 끝나고, 애매한 문제도 예전처럼 1초 정도면 풀린다.

| 방식 | 강의자료 문제 정답 | 걸린 시간 |
|---|---|---|
| 제미나이만 사용 | 15문제 중 15문제 | 약 1.1초 |
| Jev와 제미나이 동시 사용 | 17문제 중 17문제 | 약 0.2초 |

## 설치

1. `extension/config.example.js`를 `extension/config.js`로 복사하고 Google AI 키와 TypeSafe 키를 넣는다.
2. 크롬 `chrome://extensions`에서 개발자 모드를 켜고 `extension` 폴더를 압축해제된 확장 프로그램으로 불러온다.
3. 퀴즈앤 참가 화면을 새로고침한 뒤 PIN으로 들어가면 문제가 뜰 때마다 알아서 답을 누른다.
